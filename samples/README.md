# Faktel sample apps

Two small native apps that run the real Faktel pipelines on real photos, fully on-device:

| | Android | iOS |
|---|---|---|
| UI | Jetpack Compose (Material 3) | SwiftUI |
| Location | [`android/`](android) | [`ios/`](ios) |
| Faktel via | Gradle composite build (`includeBuild`) | local Swift package [`ios/FaktelOnnxRuntime`](../ios/FaktelOnnxRuntime) + `Faktel.xcframework` |
| Integration code | [`FaktelEngine.kt`](android/app/src/main/kotlin/io/github/cybersafetyid/faktel/sample/FaktelEngine.kt) | [`FaktelEngine.swift`](ios/FaktelDemo/FaktelEngine.swift) |

Each app has two tabs:

- **Selfie check** - `FaceAnalyzer`: face box + 5 landmarks, quality gate, passive liveness, head pose.
- **KTP scan** - `KtpScanner`: card outline, perspective-rectified card, sharpness, glare, portrait placement.

Both start on a bundled sample so the first screen is never empty; **Pick photo** analyses any image from your library.
The ~60 lines in `FaktelEngine.*` are all the Faktel code there is - copy them into your app.

Models come from [`../models`](../models) and sample images from [`assets/`](assets); nothing is duplicated.

## Run on Android

Requires JDK 21 and an Android SDK (`local.properties` with `sdk.dir=...`).

```bash
cd samples/android
./gradlew :app:installDebug          # emulator or device with API 24+
```

## Run on iOS

Requires macOS, Xcode and [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
./gradlew :faktel:assembleFaktelXCFramework      # once, from the repo root
cd samples/ios
xcodegen generate
open FaktelDemo.xcodeproj                        # run on an iPhone simulator or device
```

Never add real KTP photos to this repository.

## Notes

- The first run after install is slower (model load, JIT). Numbers in the screenshots are from an arm64 Android emulator (Pixel 10 Pro AVD,
  Android 37) and an iPhone 17 Pro Max simulator, **not** representative of real devices - see [tuning](../docs/guides/tuning.md).
- The apps are demos, not templates for camera capture; see the [Android](../docs/guides/android.md) and
  [iOS](../docs/guides/ios.md) guides for CameraX / `CVPixelBuffer` frame conversion.
